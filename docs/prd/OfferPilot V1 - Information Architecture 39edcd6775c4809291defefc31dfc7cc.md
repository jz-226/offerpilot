# OfferPilot V1 - Information Architecture

## 1. 信息架构目标

OfferPilot 的信息架构围绕用户三个核心问题设计：

1. 我距离目标 Offer 还有多远？
2. 我今天最应该做什么？
3. 我为什么要完成这个任务？

产品结构围绕：

目标建立 → AI分析 → 行动执行 → 成长反馈 → 状态更新

形成完整闭环。

---

# 2. 产品整体架构

```
OfferPilot

├── 用户目标层
│
├── AI分析层
│
├── 成长执行层
│
└── 用户管理层
```

---

# 3. 页面结构

## ① Splash（启动页）

### 页面目的：

建立品牌认知。

### 用户需求：

“这是什么产品？”

### 核心信息：

OfferPilot

帮助你每天完成距离目标 Offer 最近的一步。

---

# ② Onboarding（用户引导）

### 页面目的：

帮助用户理解产品价值。

### 用户需求：

“这个产品如何帮助我？”

### 核心内容：

介绍：

- Goal-Oriented AI
- 每日一个关键任务
- Evidence驱动成长

---

# ③ 创建目标（Create Goal）

### 页面目的：

收集用户目标信息。

### 用户需求：

“我要去哪里？”

### 输入：

- 目标岗位
- 城市
- 时间
- 当前情况

### 输出：

进入 AI 分析。

---

# ④ AI分析报告（AI Analysis）

### 页面目的：

帮助用户理解当前差距。

### 用户需求：

“我距离目标还有多远？”

### 展示：

- 能力分析
- Gap分析
- 成长建议

---

# ⑤ Dashboard（首页）

### 页面目的：

提供每日行动入口。

### 用户需求：

“今天我要做什么？”

### 核心展示：

- 今日唯一任务
- Offer Readiness
- AI建议
- 成长进度

---

# ⑥ Roadmap（成长路线）

### 页面目的：

展示长期成长路径。

### 用户需求：

“我要怎么走？”

### 展示：

- 当前阶段
- 下一阶段目标
- 已完成节点

---

# ⑦ Learning Hub（学习中心）

### 页面目的：

提供匹配资源。

### 用户需求：

“我要在哪里学习？”

### 内容：

- B站资源
- 官方文档
- GitHub
- 案例资料

---

# ⑧ Daily Reflection（每日成长汇报）

### 页面目的：

收集成长 Evidence。

### 用户需求：

“我的努力有没有产生价值？”

### 输入：

- 学习总结
- 笔记
- 项目成果

### AI输出：

- 反馈
- 能力变化
- 下一步建议

---

# ⑨ Profile（我的）

### 页面目的：

管理用户信息。

### 包括：

- 目标设置
- 历史记录
- 成长数据
- 设置

---

# 4. 核心页面关系

```
创建目标

↓

AI分析报告

↓

Dashboard

↓

Roadmap

↓

Learning Hub

↓

Daily Reflection

↓

成长数据更新

↓

Dashboard重新展示
```

形成持续循环。

---

# 5. 信息架构设计原则

## 原则1：目标优先

所有页面围绕目标 Offer 服务。

---

## 原则2：减少决策成本

首页不展示大量信息。

只告诉用户：

今天最重要的一件事。

---

## 原则3：数据闭环

用户产生的每一次行动，都应该影响后续 AI 推荐。
