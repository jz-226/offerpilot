# OfferPilot Showcase

> 以 OfferPilot 真实 App UI 构建的产品展示页面。

## 预览

访问 [offerpilot-showcase.vercel.app](https://offerpilot-showcase.vercel.app)（部署后更新链接）

## 技术栈

- **Next.js 16** + React 19
- **Tailwind CSS 4**
- **Motion** (Framer Motion) — 交互动画
- **TypeScript**

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000

## 设计理念

- **App 是主角，手机只是容器** — 不展示硬件，展示真实产品体验
- **100% 真实 UI** — 所有屏幕内容来自 OfferPilot 实际页面，像素级还原
- **Apple 式产品叙事** — 逐层加载动画、数字计数、进度条动态展开
- **3D 交互** — 鼠标驱动手机视差旋转 + 玻璃反射效果

## 展示流程

Goal → AI Analysis → Roadmap → Learning → Ready
